# Glossary it → en

The single reference for the English version of the site and the courses. Every translator (human or
agent) uses these terms; if a term is missing, add it here first, then translate.

## Rules

- Translate prose only. Code, commands, output, file names, identifiers, URLs and CSS classes stay
  identical, including Italian identifiers in the code (`maniOrdinate`, `riconosciMossa`…).
- Italian code comments inside code blocks stay as they are, unless the same block is shown as an
  exercise to copy: then translate the comments only.
- Tone: second person ("you"), short sentences, plain words, like the Italian original. No
  exclamation marks the original does not have.
- Signature: "Prof. Giuseppe Bosi" in both languages; in English "by Prof. Giuseppe Bosi".
- Author line in English: "Giuseppe Bosi, Master's-level degree in Electronic Engineering (5-year Italian
  Laurea, pre-reform, EQF level 7), Teacher of Computer Science and Technology". Short form allowed:
  "Master's equivalent degree in Electronic Engineering". Never "M.Sc.", "licensed engineer", "Ing.".
- Author site in English pages: https://www.giuseppebosi.com/en/
- Page names in the menu keep the Italian URL (`/sfida/` → `/en/sfida/`) but get an English label.
