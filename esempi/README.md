# Examples

Runnable versions of the code in the teaching pages of https://mano.giuseppebosi.com
(Italian and English). Each folder opens on StackBlitz with no account, for example:

    https://stackblitz.com/github/JoeBosi/hand-gesture-recognizer/tree/main/esempi/<folder>

| Folder | Used by |
|---|---|
| `p5-lesson-01/` | School course, lesson 1 (p5.js + ml5.js): program and 4 solved exercises |
| `corso-ts/lezione-05` ... `lezione-10` | TypeScript course, lessons 5 to 10 (Vite + TypeScript + MediaPipe + Three.js) |
| `tutorial-mano/` | The long tutorial: the finished project |

The webcam does not work inside StackBlitz's small preview frame: open the preview in a new tab.
Camera images stay in the browser; nothing is uploaded. Locally: `npm install` then `npm run dev`
(the p5 folder is plain HTML: `npx serve`).
