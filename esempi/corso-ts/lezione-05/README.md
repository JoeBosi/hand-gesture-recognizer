# Course lesson 5: a fake hand on a canvas

State of the project after exercises 5.1 to 5.5 of the TypeScript course (https://mano.giuseppebosi.com/en/corso/).

```
npm install
npm run dev
```

You should see a page with a button "Cambia posa" and a dark-blue canvas with a stylised hand
(blue bones and joints, white fingertips). Each click toggles between open hand and fist.
