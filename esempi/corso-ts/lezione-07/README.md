# Course lesson 7: the webcam

State of the project after exercises 7.1 to 7.6 of the TypeScript course (https://mano.giuseppebosi.com/en/corso/).

```
npm install
npm run dev
```

Open the address it prints (`http://localhost:5173`), press "Accendi la camera" and allow the camera.
The webcam does not work in the preview frame of online editors (browsers block the camera in embedded frames
from another site): in StackBlitz, open the preview in a new tab with the button at the top of the preview.
No image leaves the browser.
