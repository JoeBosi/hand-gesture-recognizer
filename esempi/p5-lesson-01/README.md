# Lesson 1: points and bones of the hand (p5.js + ml5.js)

Complete, runnable version of lesson 1 of the school course
(https://mano.giuseppebosi.com/scuola/mkdocs/lezioni/01-punti-della-mano/).

- `index.html` + `sketch.js`: the lesson program (webcam, 21 green points, white bones).
- `exercise-1.html` ... `exercise-4.html`: the four exercises, solved.

Open `index.html` through a web server (the browser only allows the webcam on https or localhost),
for example `npx serve` in this folder, or open the folder on StackBlitz and open the preview in a new tab.
The webcam images stay in the browser. Libraries: p5.js 1.11.10 and ml5.js 1.4.0, pinned.
